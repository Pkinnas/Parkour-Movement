## About

This parkour system was developed as part of my thesis, with the objective of exploring and implementing different movement mechanics in a game environment.

## Features

- Wall Running
- Wall Climbing
- Vaulting
- Sliding
- Ledge Grabbing
- Wall Jumping
- Rolling

## Technologies

- Unity
- C#
